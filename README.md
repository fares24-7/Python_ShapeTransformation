# Python_ShapeTransformation

Python scripts that draw 2D shapes and transform them (scaling, moving, flipping) using NumPy and Matplotlib.

## Repository Contents

* **`app.py`**: Renders a multi-part 2D frog graphic and applies linear matrix transformations (scaling and reflection).
* **`app2.py`**: Renders a 2D house outline and applies affine transformations (scaling combined with translation).
